## 信息架构说明（IA）
1. **双索引并行**：日期索引用于追时间线；模块索引用于按能力域复用。
2. **功能页独立**：每个任务单独成页，固定 6 段结构，便于后续自动化生成与审计。
3. **源码归档分层**：`docs/` 放可读说明，`archive/` 放原始产物，避免文档与代码耦合。
4. **占位任务显式化**：对空目录任务保留页面并标注状态，避免“隐性遗漏”。
