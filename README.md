## 自动化维护
- 同步：`python3 scripts/sync_nightly.py --source-root /root/.openclaw/workspace --repo-root .`
- 重建索引：`python3 scripts/build_index.py --repo-root .`
- Actions：`.github/workflows/nightly-sync-index.yml`（定时 + 手动）

## 信息架构说明（IA）
1. 双索引并行：日期索引追踪时间线；模块索引支持能力复用。
2. 功能页独立：每个任务固定 6 段结构，便于审计与自动更新。
3. 文档与产物分层：`docs/` 放说明，`archive/` 放原始产物。
4. 占位显式化：空目录任务也生成页面并标注状态，避免遗漏。
