# CronFlow（定时任务可视化扫描）

- 日期：`2026-04-04`
- 来源：`archive/nightly-tools/2026-04-04-cronflow`

## 功能简介
零依赖 cron 可见性工具，扫描用户可访问 cron 源并估算 next-run，标注同分钟冲突。

## 背景 / 目的
解决“cron 配了就忘”问题，给夜间/晨间巡检提供统一可读面板。
